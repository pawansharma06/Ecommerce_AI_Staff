# ShopAI Agent Rules

## Architecture

Backend: Java 21 + Spring Boot 3.x + Maven
Database: PostgreSQL 16 + pgvector
Cache: Redis 7
Frontend: React 18 + TypeScript + MUI
Infrastructure: Docker + Docker Compose + Nginx

## Rules

1. Do not introduce a new framework without approval.
2. Do not introduce a new database without approval.
3. Do not create a new microservice unless explicitly requested.
4. Do not modify unrelated modules.
5. Do not put business logic in controllers.
6. Do not call Shopify directly from controllers.
7. Do not call LLM providers directly from controllers.
8. Do not put database queries inside React components.
9. Never expose credentials to the LLM.
10. Never expose Shopify access tokens to the frontend.
11. All tenant-owned data must be tenant isolated.
12. All database schema changes must use Flyway migrations.
13. All important business logic requires automated tests.
14. Dangerous AI actions require authorization and human approval.
15. Do not execute arbitrary SQL generated by an LLM.
16. Do not execute arbitrary code generated by an LLM.
17. Do not invent Shopify API endpoints or GraphQL fields.
18. Do not invent undocumented provider APIs.
19. Do not upgrade major dependencies without approval.
20. Do not rewrite working code unnecessarily.
21. Do not silently change the architecture.
22. Prefer simple solutions over unnecessary infrastructure.
23. Every external integration must be behind an interface.
24. Every LLM provider must be behind an interface.
25. Every graph implementation must be behind an interface.
26. Every channel must be behind an interface.
27. Never put secrets in source control.
28. Never log secrets, API keys, or credentials.
29. Never put secrets or credentials into LLM prompts.
30. Always maintain tenant boundaries in every query.
31. Shopify is the source of truth for live commerce data.
32. PostgreSQL is the source of truth for application data.
33. Vector RAG is the source of truth for indexed knowledge.
34. Graph RAG is the source of truth for entity relationships.
35. The Tool Engine is the only mechanism for external actions.
36. The LLM is the reasoning/generation layer only.
37. All Shopify access goes through ShopifyClient.
38. All AI actions go through the Tool Engine.
39. Before changing architecture, explain the reason and wait for approval.
40. Use HNSW indexes for vector similarity columns.
